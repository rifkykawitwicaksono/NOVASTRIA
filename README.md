# NOVASTRIA

Website statis NOVASTRIA. File utama: `index.html`; aset berada di folder `assets/`.

## Deploy GitHub Pages
Buka Settings → Pages → Deploy from a branch → pilih `main` dan folder `/(root)` → Save.

## Catatan
Versi ini adalah frontend demo. Status anggota dan referral belum aman untuk transaksi nyata; dibutuhkan backend, database, dan verifikasi pembayaran sebelum operasional.
